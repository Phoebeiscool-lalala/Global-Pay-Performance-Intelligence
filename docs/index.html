Features

核心能力

Phase 2 已实现的完整决策支持模块。

Regional Intelligence

四市场矩阵、底层 Claim 状态、可信度、Common Practice、Market Difference 与 Evidence Gap。

Pattern Explorer

模式范围、组成、市场、Company Archetype、支持与反向证据、限制、状态及核验日期。

Design Library

绩效和销售激励结构、Potential Advantages、Trade-offs、Operational Complexity 与 Evidence。

Scenario Lab

输入业务 Context 自动生成三个不排序的可选结构，展示证据、假设与缺口。不输出"推荐"。

Vendor Fit

逐字段 Capability Coverage Matrix、差异化 RFI 问题包。仅输出 FIT/PARTIAL/GAP/UNKNOWN，不排名。

Market Signals

Signal Strength、Direction、Supporting Evidence、Counter Signals、Confidence 与 Why It Matters。
